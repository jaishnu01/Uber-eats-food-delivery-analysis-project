# UberEats – Food Delivery Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyse food delivery business performance in India. It provides insights into sales, orders, food categories and customer trends.

## Key Features
- Executive Overview with KPI cards.
- Monthly Sales Trend Analysis.
- Sales by Food Category.
- Order Status Analysis.
- Interactive slicers and dashboard navigation.
- India-focused geographical analysis.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX

## Objective
To transform food delivery data into meaningful business insights through interactive visualisations and data analysis.
